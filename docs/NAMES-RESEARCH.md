# Wrestle Angels: Survivor 2: English terminology, promotions, belts, existing resources

Researched 2026-10-18. Labels: **official** = Success's own site. **fan** = an English fan source (TV Tropes, GameFAQs, the 2007 WAS2 fan blog). **mine** = my own suggestion, with no English source found.

## 0. Things to know first

- **Publisher.** Survivor 2 was announced by Success in July 2007, but the rights then went to **Tryfirst** (Yuke's group), which released it on 2008-11-06. Success published Survivor 1 (2006).
- **Official romanizations exist for part of the cast.** The archived official site, `success-corp.co.jp/software/ps2/wa/was2/char/<name>.html` (2008, via the Wayback Machine), gives each wrestler's page a romanized filename. Examples: `bomber_kishima`, `hibiki_izayoi`, `yuuri_kusunoki`, `riyu_kikuchi`, `satomi_kozima`, `freia_kagami`, `calen_nielsen`, `rosanna_chan`, `cuty_kanai`, `ledy_cody`, `corey_sniper`, `win_mirror`, `cindy_won` / `bridget_won`, `phantom_rose1`, `daisy_cry`, `janis_crea`. These filenames are the only official romanizations. They are often careless (`cuty`, `ledy`, `kozima`), so the CSV follows them for names and corrects spelling only where the katakana clearly means an ordinary English word.
- **来島 is read きしま: "Bomber Kishima", not "Kurishima".** Sources: the official filename, ja.wikipedia (来島恵理（きしま えり）), TV Tropes and GameFAQs.
- **Official kana readings exist for the twelve Wrestle Angels Ai (愛) guest characters.** They come from the archived official Ai site (`.../wa/wa_i/char500-511.html`). Examples: 六角葉月 = むすみ はづき, 寿零 = ことぶき ぜろ, 佐尾山幸音鈴 = さおやま さおり.
- **Most of the cast has no official English text.** The Wrestle Angels games have never been released in English: there is no Steam or official English release, and no English version of Survivor or Survivor 2.

## 3. Title belts

These names come from series text on ja.wikipedia. Check the actual Survivor 2 belt strings in the game's data, because this research found no Survivor 2–specific belt list.

- IWWFヘビー級 (世界ヘビー級) = IWWF (World) Heavyweight Championship
- IWWFアジアヘビー級 = IWWF Asian Heavyweight Championship. NJW treats this as its top belt.
- IWWFジュニアヘビー級 = IWWF Junior Heavyweight Championship
- IWWFタッグ / 世界タッグ = IWWF (World) Tag Team Championship
- アジアタッグ = Asian Tag Team Championship
- AACヘビー級 = AAC Heavyweight Championship
- WWCAヘビー級 / WWCAタッグ = WWCA Heavyweight / Tag Team Championship
- GWAヘビー級 / GWAタッグ = GWA Heavyweight / Tag Team Championship
- EWAヘビー級 = EWA Heavyweight Championship
- IWWFヨーロッパヘビー級 = IWWF European Heavyweight Championship

Use the standard pattern: 王座 / ベルト = Championship / title / belt, 王者 = champion, 防衛 = title defense, 挑戦者 = challenger.

## 5. Romanization conventions used in the CSV

- Western order (Given Family) for ordinary names. Ring names keep the Japanese order: "Mighty Yukiko", "Witch Misa", "Fortuna Shizuku".
- Long vowels are not marked: Saito, Kondo, Ryuko, Hojo, Yagyu, Shishido, Ozora, Muto, Yuki. TV Tropes doubles them (Saitou, Yuuki). The official site mixes both styles (`yuuri_kusunoki` but `makoto_kondo`). Choose one style and apply it everywhere.
- Where TV Tropes builds the alter ego from the surname but the katakana uses the given name, the CSV follows the Japanese. For example, フェニックス遥 = "Phoenix Haruka" (TV Tropes: "Phoenix Date"), and the same applies to マーメイド千秋, セイレーン千春, アドミラル八島, マイトス香澄 and ジャイアントミギリ.
- Unresolved:
  - エセルド栗浜 (TV Tropes: "Exelude"; I used "Esseld")
  - ミミ吉原 / 吉原泉 (よしはら vs よしわら; no kana source)
  - 新咲 (しんざき per TV Tropes)
  - 北条沙希 (TV Tropes writes "Sachi"; I used さき)
  - ライラ神威 (TV Tropes "Raira"; "Layla" would be more natural)
  - 上戸真紀 (まき, inferred from "Macky")
